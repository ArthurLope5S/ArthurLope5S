## 🟣 03 // Projetos em destaque

Projetos desenvolvidos durante minha formação, explorando diferentes áreas da tecnologia.

### 🌐 Feira Circular — Front-end

Interface demonstrativa de uma plataforma voltada à redução do desperdício de alimentos nas feiras livres de São Paulo.

A aplicação apresenta três perfis de usuários — feirante, consumidor e organização social — com layout responsivo e interações em JavaScript.

**Tecnologias:** HTML5, CSS3 e JavaScript.

### 🤖 FeiraBot — Inteligência Artificial

Chatbot acadêmico desenvolvido com Node-RED, integrando modelos de inteligência artificial e canais de comunicação.

O projeto explora reconhecimento de intenções e entidades, memória de contexto e interações por texto e áudio.

**Tecnologias:** Node-RED, JavaScript, Groq, Gemini e Telegram API.

### 🐍 Análise de Crédito — Python

Sistema que simula a avaliação de crédito de clientes a partir de informações financeiras e pontuação de crédito.

O projeto utiliza validação de entradas, estruturas condicionais e cálculo de juros.

**Tecnologias:** Python.

### 🗄️ Feira Circular — Banco de Dados

Modelagem de banco de dados para uma proposta de plataforma que conecta feirantes, consumidores e organizações sociais.

O projeto contempla entidades, atributos, relacionamentos e regras de integridade para apoiar o gerenciamento de ofertas e reservas de alimentos.

**Tecnologias:** Oracle SQL Developer Data Modeler e modelagem de banco de dados.
